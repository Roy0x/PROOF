PROOF - WINDOWS QUICK START
===========================

1. Use Windows with Python 3.11 or newer installed. PROOF does not install Python.
2. Extract the entire ZIP first. Do NOT run PROOF from inside the ZIP preview.
3. Open the extracted PROOF-v0.8-offline-windows folder.
4. Double-click run.bat. It creates or reuses .venv in this folder.
5. If Playwright Chromium is missing, read the disk-space guidance and type Y only if you agree to its download.
6. Keep the terminal window open. Your browser should open http://127.0.0.1:8000/.
7. If it does not, type that exact address into your browser.

IMPORTANT
---------
- First-time Python package and Chromium installation needs internet access and sufficient free disk space.
- Allow at least 1 GB free on the browser-cache drive; Chromium may use several hundred MB.
- Existing packages and a working Chromium are reused without downloading them again.
- No paid service or Nebius API key is needed for the local verification demo.
- The server listens only on 127.0.0.1. Do not expose or forward port 8000.
- Do not close the terminal window while using the site.

QUICK HEALTH CHECK
------------------
Open:
  http://127.0.0.1:8000/api/health

Expected result:
  {"status":"ok", ...}

If startup fails, read the terminal error. Check Python, internet access, folder permissions, browser-cache permissions, disk space, and whether another app uses port 8000.
